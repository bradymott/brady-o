# Burner "action figures" the user wants in the game

The user is sending pictures of funny burner action figures and wants every one in Brady-O Burns, looking as close to the pictures as possible.

**How to use them:**
- Match each figure's outfit, colors, hair and signature gear on our own rounded 3D characters, in the game's style.
- Use the pictures as a costume reference only. Don't reproduce the packaging art or text.
- Each figure becomes a named NPC type usable by every world, with its accessories as props or held items where it makes sense.
- Reference images are listed with each figure; open them with the Read tool to see them.
